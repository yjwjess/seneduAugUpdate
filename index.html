01 / 전체 보기

무엇이 달라졌을까요?

선생님이 알아두면 좋은 변화, 네 가지.

01 · 연결
한 번의 로그인으로 연계 서비스 접근
02 · 도구
수업용 에듀테크 및 클래스룸 연계 확대
03 · 관리
학생 계정 생성·분류 절차 개선
04 · 화면
수업 현황과 학습 기록 확인 동선 개선
출처: 사용자 제공 업데이트 영상 요약
02 / SSO

한 번 로그인.
여러 서비스.

SEN스쿨과 똑똑SEN 등 연계 서비스 이용 절차를 간편하게.

SSO = Single Sign-On, 한 번의 인증으로 연계 시스템에 접속하는 방식
SEN스쿨 로그인 후 연계 메뉴에서 똑똑SEN으로 이동
교사 계정의 실제 연계 상태와 추가 인증 여부는 개별 확인
출처: 사용자 제공 업데이트 영상 요약 · 해당 SSO 화면은 첨부 학생 매뉴얼에 없음
03 / 에듀테크 연계

수업 도구를
더 가깝게.

연계 에듀테크 서비스 및 구글 클래스룸과의 사용 흐름을 소개합니다.

교사 인증 계정에 적용되는 지원 서비스·라이선스 조건 확인
아트봉봉스쿨 등 연계 도구는 실제 제공 목록에서 확인
교사가 학습 활동을 안내하고 학생은 자신의 수업 공간에서 확인
학생용 매뉴얼 v6.1 · 4쪽 · 화면 예시
업데이트 내용: 영상 요약 · 화면 예시: 학생 매뉴얼 4쪽
04 / 계정 관리

학급 운영,
설정은 간결하게.

명렬표 업로드와 그룹 라벨을 활용하는 계정 관리 개선 안내.

엑셀 기반 일괄 생성 및 오류 확인 절차 개선
학년·반·교과·분반 등 필요에 따른 그룹 라벨링
계정 생성 후 학생 로그인, 소속 반·그룹 확인
출처: 사용자 제공 업데이트 영상 요약 · 교사용 관리자 화면은 학생 매뉴얼에 없음
05 / 학생 화면

학생은 어디서
수업을 볼까요?

학생용 「나의 수업」에서 소속 클래스와 수업 자료·과제를 확인합니다.

나의 수업에서 참여 중인 클래스 접근
자료 메뉴에서 수업 콘텐츠 보기
과제 메뉴에서 제출 상태 및 피드백 확인
학생용 매뉴얼 v6.1 · 6쪽 · 화면 예시
출처: AIEP 초등 학생 매뉴얼 v6.1, 4~7쪽
06 / 과제 흐름

과제 제출부터
피드백까지.

학생이 실제로 마주하는 과제 상세 화면을 확인하세요.

클래스별 과제 목록에서 과제 선택
제출 내용 작성 및 제출 여부 확인
선생님 피드백·평가 정보가 표시되는 화면 확인

결과는 쌓이고,
흐름은 보입니다.

학습 이력을 학생 화면에서도 확인할 수 있습니다.

「수업 기록」에서 클래스 기록·월기록 확인
학습 참여·과제 제출 관련 통계 화면 확인

클래스와 알림도
한곳에서.

09 / 선생님 체크리스트

수업 전,
5분 점검.

업데이트 후 첫 수업 전에 한 번 확인해 주세요.

① senedu.kr 접속 및 교사 계정·연동 상태 확인
② 담당 학급·교과 그룹 및 학생 계정 확인
③ 연계 도구와 똑똑SEN 접근 테스트
④ 학생에게 임시 비밀번호 전달 및 최초 로그인 지도
⑤ 학생과 함께 자료 열기·과제 제출·학습 기록 위치 확인
출처: 사용자 제공 안내 내용 재구성
10 / 시범 수업

직접 해보면
더 쉽습니다.

학급에서 바로 적용하는 10분 시범 활동.

1분 · 로그인
학생이 SEN스쿨 로그인
3분 · 수업
나의 수업에서 클래스 열기
4분 · 과제
과제 열람 및 제출 흐름 체험
2분 · 확인
수업 기록과 알림 확인
활동 순서는 매뉴얼의 학생 메뉴를 이용한 교육 예시
